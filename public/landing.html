TIDAK HARUS. Pilih paket Lifetime — bayar sekali Rp 7jt, pakai selamanya. Atau pilih paket Hemat kalau mau fleksibel Rp 108rb/bulan.
Staff saya tidak terbiasa dengan komputer/HP, bisa?
BISA. Kami latih sampai bisa. Tutorial bahasa Indonesia simple, support WhatsApp, dan kami bantu setup data awal. Banyak ustadz/ustadzah yang awalnya gagap teknologi, sekarang mahir.
Bagaimana kalau internet di pesantren lemah?
AMAN. Aplikasi kami ringan, jalan di sinyal 3G. Data tersimpan otomatis ke server, gak perlu install di komputer.
Apakah data pesantren kami aman?
AMAN. Backup harian otomatis, server di Indonesia, hak akses per peran. Pesantren A tidak bisa lihat data Pesantren B. Privasi 100% terjaga.

BEBAS. Tidak ada kontrak ikat. Stop kapan saja, data bisa di-export ke Excel. Tanpa penalti, tanpa drama.
Bisa custom sesuai kebutuhan pesantren kami?
BISA, tergantung paket. Self-hosted bisa custom penuh termasuk branding. Subscription bisa request fitur via support.
